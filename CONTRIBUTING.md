# Contributing

Thanks for contributing to Codex Ext.

1. Fork the repository and create a focused branch.
2. Run `npm install` and `npm run compile`.
3. Use `F5` in VS Code to test in an Extension Development Host with the
   official OpenAI Codex extension installed.
4. Keep new UI strings localized in both `l10n/bundle.l10n.json` and
   `l10n/bundle.l10n.zh-cn.json`.
5. Submit a pull request describing the user-visible behavior and validation.

Please do not add analytics, advertising, paid features, or dependencies on
unofficial remote Codex services.
